# MVV Experience 3.1.2

Versión Production Ready construida sobre MVV Experience 3.0/3.1, conservando el diseño, colores, tipografías, imágenes, animaciones y experiencia de navegación.

## Cambios de esta versión

- Integración de cinco documentos oficiales en formato PDF.
- Rutas simplificadas y estables para TSB-101, TSB-102, TSB-103, OCB-201 y OCB-202.
- Eliminación de referencias a archivos Word en la biblioteca documental.
- Validación de enlaces internos y recursos locales.
- Preparación para publicación en GitHub Pages, Cloudflare Pages o servidor web convencional.

## Biblioteca documental

- `assets/documents/tsb/TSB-101.pdf`
- `assets/documents/tsb/TSB-102.pdf`
- `assets/documents/tsb/TSB-103.pdf`
- `assets/documents/ocb/OCB-201.pdf`
- `assets/documents/ocb/OCB-202.pdf`

## Actualización futura de documentos

Para actualizar un documento, sustituya el PDF correspondiente sin cambiar su nombre. Así, los enlaces del portal permanecerán vigentes.

## Publicación

Publique el contenido de esta carpeta en la raíz del repositorio o servicio de alojamiento. El archivo principal es `index.html`.
