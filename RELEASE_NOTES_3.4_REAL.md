# MVV Experience 3.4 REAL — Configuration Edition

- Las variables `true/false` de `config.js` ahora tienen un efecto real y verificable.

- TSB, OCB, propuestas, contacto, WhatsApp, correo, sitio web, vCard y C11 son controlables desde `config.js`.
- Se agregó ocultamiento robusto mediante `hidden`, clase CSS y estilo inline prioritario.
- Se corrigió el identificador de caché de `config.js` y `script.js`.
- No se modificó el diseño visual del sitio.
