# MVV Experience 3.4 — Configuration Edition

Actualización funcional sobre la versión 3.3, sin rediseñar la interfaz.

## Cambios principales
- Funcionamiento verificado de `showPrices`.
- Nuevos controles `true/false` para WhatsApp, correo, sitio web, vCard, contacto, C11 y nota comercial.
- Control de visibilidad de TSB, OCB y Propuestas Vigentes desde `config.js`.
- Rutas de documentos y datos de contacto centralizados.
- Versionado automático de imágenes, PDF y vCard para reducir problemas de caché.
- Compatibilidad mejorada con navegadores sin `IntersectionObserver`.
- Manual ampliado de configuración y resolución de problemas.

## Diseño
No se modificaron colores, imágenes, tipografías, tarjetas, estructura visual ni animaciones aprobadas.
